# Guia de Contribucion

¡Gracias por querer mejorar este proyecto! Sigue estas reglas para colaborar:

## Como reportar un error
Si encuentras un fallo en el sistema de registro:
1. Abre un "Issue" en GitHub.
2. Describe el error detalladamente.
3. Incluye los pasos para reproducirlo y qué resultado esperabas.

## Como proponer una mejora
Si tienes ideas para nuevos modulos (ej. monitoreo de temperatura):
1. Abre un "Issue" explicando la mejora.
2. Espera a que lo discutamos antes de empezar a programar.

## Checklist para enviar un Pull Request (PR)
Antes de enviar tu código, asegurate de cumplir con lo siguiente:
- [ ] Hice un fork del repositorio y cree una rama nueva.
- [ ] Mi código no rompe las funciones existentes.
- [ ] Agregue comentarios explicando las partes complejas.
- [ ] Actualice el README.md si agregue nuevas funciones.
